# Arman-Project

- `grandma_stock/`: the **main reusable kit** for fully edited videos from the user's images + voiceover (stock footage, text animation, SFX, music). Read `grandma_stock/README.md`, or use the `grandma-stock-video` skill.
- `video/`, `blackhole/`: older 2D animated (stickman) video projects.
